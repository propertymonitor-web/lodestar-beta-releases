Contacts backup keep your radio's contacts in a file on this computer

Saves the names and public keys of the contacts in your radio to a file you choose on this computer, and can put missing ones back after a reset or on a new radio. It never touches private keys, and it only adds: contacts already on the radio are never changed or removed. The file is not encrypted, so keep it somewhere private. Test feature: it has not been run on a real radio yet.
